# Chapter 8. Building a Geospatial Data Lakehouse with Apache Parquet and Apache Iceberg

In this chapter we cover in details the process of building a geospatial data lakehouse using Apache Sedona, Apache Parquet, and Apache Iceberg.
We will explore the recent native geospatial support in Apache Parquet and Apache Iceberg, and how to leverage these capabilities to create a scalable and efficient geospatial data lakehouse.
We will explore in details open source file formats like:
- Apache Parquet with native geospatial support
- Apache Iceberg with native geospatial support
- GeoParquet

In the hands on example we will build a geospatial data lakehouse using Apache Sedona, Apache Parquet, and Apache Iceberg.
We will use Apache Airflow to schedule out code we follow the medallion architecture for building data lakehouses.

To run Apache Airflow please follow the main README instructions in the root of the repository.
