# Chapter 9. Using Apache Sedona with Cloud Data Providers

In this chapter we will show you how to install Apache Sedona on popular cloud data platforms such as
- Amazon EMR
- AWS Glue
- Google Cloud Dataproc
- Databricks
- Azure Fabric
- Snowflake
- Ververica

We also cover how to use Apache Sedona in Wherobots which is the geospatial data platform from original creators of Apache Sedona.

You can find in the `book/chapter9` folder the code examples and resources for this chapter.
